# Fuentes

Bibliografía completa del proyecto. Todas las referencias con PMID se han verificado en PubMed: título, revista, año y DOI. Las guías sin PMID enlazan a la web del organismo que las publica.

**Tipos:**

- **guía**: guía de práctica clínica;
- **consenso**: consenso, declaración o posicionamiento;
- **RS/MA**: revisión sistemática o metaanálisis;
- **ECA**: ensayo clínico aleatorizado;
- **observacional**: estudio observacional o de precisión diagnóstica;
- **revisión**: revisión narrativa.
